# Student Performance Prediction System

A Machine Learning based web application developed using Flask and Scikit-learn to predict student pass/fail performance using study hours, attendance, and previous marks.

## Technologies Used
- Python
- Flask
- HTML/CSS
- Scikit-learn
- Pandas
- NumPy

## Features
- Student performance prediction
- Machine learning integration
- Responsive web interface
- Real-time prediction results

## Project Modules
- Data Preprocessing
- Model Training
- Prediction System
- Result Visualization

## Future Enhancements
- Database integration
- User login system
- Performance analytics dashboard
